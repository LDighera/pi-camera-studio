project follows [Semantic Versioning](https://semver.org/) while it is in alpha.

## [Unreleased]

## [0.1.0-alpha.1] - 2026-07-17

Initial public alpha release.

### Added

- Full-sensor JPEG and PNG still capture.
- 1080p H.264 video recording with optional AAC microphone audio.
- Stop-motion sessions with onion-skin preview, frame management, optional
  soundtrack, and FFmpeg rendering.
- Local NanoDet object detection for 80 COCO categories, with annotated stills.
- Touch-oriented Qt interface, startup diagnostics, and a hardware smoke test.
- Integrity verification for the bundled OpenCV Zoo NanoDet model.
- Raspberry Pi OS source and wheel packaging for apt-managed runtime
  dependencies.
